# BIM Dating crowdfunding landing page

## Campaign configuration

`lib/crowdfunding.ts` is the central configuration. The owner confirmed the end
as **16 November 2026 at 23:59 Europe/Paris**, stored as
`2026-11-16T22:59:00Z`. The public Ulule API returned `22:59:19Z`; the owner's
explicit minute-level instruction takes precedence.

The page is available at `/{en,fr,de,es,it,lb}/crowdfunding`. The shared desktop
and mobile navigation includes a temporary, dictionary-backed "Ulule" item
pointing to the current language's landing page. Its client-side visibility uses
the same campaign deadline, rechecks on timers and tab restoration, and removes
the item at expiry. A click-time check also sends late clicks to the homepage.
Existing header, footer and locale menu are inherited from the site layout.

At and after the deadline, middleware sends a **307** to the same language's
homepage, retaining the query string and setting `Cache-Control: no-store`.
The page also checks expiry on the server and exports `force-dynamic` and
`revalidate = 0`. A client guard handles open tabs, focus and history restoration.
No scheduled deployment or API call is needed to retire the page.

## Editorial sources

Verified on 27 September 2026:

- Campaign: https://fr.ulule.com/dating-app-rencontre-en-video-/
- Public campaign data: https://api.ulule.com/v1/projects/212901
- Existing BIM presentation and app links in the site's dictionaries/pages.

The public API provides the French project, funding and team descriptions even
though the embedded page data has null values for these fields. The six local
translations are original summaries based on those descriptions. The progressive
experience explains discovery, contact and video conversation without inventing
unlock rules, a matching protocol or a delivery schedule.

Funding priorities are clearly presented as future work. No live amount raised,
financial target or reward schedule is duplicated. Ulule includes conditional
financial bonuses in some offers, and a delivery field of January 2026 that
predates the campaign: check those conditions before advertising specific offers.
The landing page directs readers to the full current offer terms on Ulule.

## Analytics

The existing GTM integration receives `crowdfunding_ulule_click` with `campaign`,
`language`, `placement` (`hero`, `funding`, `final`) and `link_url`.
The click event is emitted only when the existing `analytics` consent is true.
Tracking failures never block the link. Map this event in the existing GTM/GA
configuration if desired; it is an outbound click, not a completed contribution.
The existing global GA/GTM consent configuration is otherwise unchanged.

## Production deployment

The repository's origin is `https://github.com/ziegdev/Bim-Website.git`.
Local `main` tracks `origin/main`. `vercel.json` declares Next.js, `bun install`
and `bun run build`. `package.json` maps `build` to `next build`; `start` is
`next start` for local production verification.

After approval, commit the reviewed files on a working branch, push it and use
the linked Vercel project's Preview deployment. Once verified, merge into the
branch configured as Production Branch in Vercel (expected to be `main`, but the
remote project setting is not available in the repository). A push/merge to that
configured branch triggers production deployment when the Git integration is
enabled. Confirm that the same project owns `bim-dating.com` and retains its
existing environment variables. Do not deploy as a static export.

No deployment configuration, API route, secret, dependency or lockfile change is
required for this feature. The date is already configured, so no new environment
variable or cron job is needed. No commit, push or deployment was performed.
